First release. Sends each world its own required resource packs, and warns at startup when a pack link is dead.

## What it does

- Each world has an ordered list of packs, sent together with the multi-pack API. Moving between worlds with the same packs sends nothing; otherwise only Butler's packs are swapped.
- Butler never removes or replaces a pack it didn't send, so another plugin's pack (BlueMapHUD's, say) stays put.
- Every pack is required. Declining, or not answering the prompt in 60 seconds, is a kick with a message that says what to do.
- A failed download is retried twice. If it still fails, the player stays in without that pack, gets one chat note, and admins are told which world and pack.
- At startup Butler downloads every pack and checks its SHA-1. A 404, timeout, wrong hash or bad address is reported with the worlds it affects, and startup doesn't wait for the check. `/butler recheck` runs it again; there's no background polling.
- Hashes are learned without hand edits, from a per-build address (`<address>/<token>/<sha1>.zip`) or from a moving address with a `.sha1` file next to it. The last good hash is kept if the `.sha1` file breaks.
- Warns at startup if `server.properties` sets `resource-pack=`, and about worlds that aren't listed.
- Commands: `/butler recheck`, `/butler reload`, `/butler status [player]`. Ops only.

## Requirements

- Paper 26.1 or later, Java 25. It won't load on 1.21.x or on Spigot.
- No plugin dependencies.

## Tested

- 23 unit tests.
- Mineflayer bots on throwaway local Paper servers, with made-up packs served from a local web server: 76 checks passed on 26.1.2, 76 on 26.2 and 75 on 26.3. Bots connect as 26.1 clients, through ViaVersion and ViaBackwards on 26.2 and 26.3. Runs included Multiverse-Core, Multiverse-Inventories, BlueMap with BlueMapHUD, and Waystation (gate walks passed on 26.1.2 and 26.2).

## Not tested

- No real game client has loaded a pack from it. How loading looks, how the kick text reads on screen, and the stacking order next to another plugin's pack are only checked by bots.
- On 26.3, walking through a Waystation gate and respawning into another world: bots behind ViaBackwards get kicked when they move, and Multiverse ignored its respawn-world setting there.
- Large packs, and server transfers.

## Install

1. Put `ResourcePackButler-0.1.0.jar` in `plugins/` and start the server once.
2. In `plugins/ResourcePackButler/config.yml`, name your packs under `packs` and list every world, each Nether and End included, under `worlds`.
3. Leave `resource-pack=` empty in `server.properties`.
4. Run `/butler reload`, then `/butler status` to see which links are live.
