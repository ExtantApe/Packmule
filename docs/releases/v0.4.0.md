Packmule can check packs that only your players can download.

## Added

- **A `check` block per pack** for packs behind a gate that admits only joining players, such as Leaf Juice's "Only players joining this server". Packmule checks the pack at a loopback address with a token read from a mode-600 file, and players still get the public address. See "Packs only your players can download" in the README.
- The config is refused if the local address isn't on this machine or the public prefix isn't the start of the pack's address. The check fails if the token file is a link, another user's, readable by others or malformed. Token requests never follow redirects, and the token is never logged.

## Upgrading

Replace the jar and restart. Configs without a `check` block work as before.

## Tested

Unit tests against a made-up gate on 127.0.0.1 (51 tests). A bot test on a throwaway Paper 26.3-249 server with a real 146 MB pack behind a made-up players-only gate: Packmule checked it locally with the token, the public address refused a request with no headers, a stranger, the token and a player who hadn't joined, and a joining bot (26.1 through ViaVersion) downloaded it, matched the SHA-1 and stayed in (12 of 12). Not yet run against Leaf Juice's own gate, which waits for its side (D220), or seen in a real client.
