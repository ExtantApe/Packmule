ResourcePackButler is now called Packmule. This release renames it and changes nothing else in how it works. The owner chose the name on 2026-11-08.

This is an early 0.x release. It has passed bot tests on throwaway servers, but no real game client has loaded a pack from it yet.

## Upgrading from ResourcePackButler 0.1.0

- Swap `ResourcePackButler-0.1.0.jar` for `Packmule-0.2.0.jar` with the server stopped.
- On first start, `plugins/ResourcePackButler/` is copied to `plugins/Packmule/` if that doesn't exist yet, so your config and last good hashes come across. The old folder is left untouched as a backup. Nothing is ever overwritten.
- **Deprecated, removed in the next release:** the commands `/butler`, `/resourcepackbutler` and `/rpb`, and the permissions `resourcepackbutler.recheck`, `.reload`, `.status` and `.notify`. They still work in 0.2.x and log a line saying what to use instead: `/packmule` and `packmule.*`.
- Pack IDs sent to clients haven't changed, so nobody re-downloads a pack because of the rename. A unit test pins them.
- Changed outright: the plugin, jar and folder are `Packmule`, and the package is `com.extantape.packmule`. No other plugin used the old package.
